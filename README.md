## The rule this page follows

No number on the page is typed by hand. The figures and table in the `inha-tb` section
render from `docs/facts.json` in that repository — a file the analysis writes and the
write-up reads — so a number on the page cannot drift from the number the code produced.

Every project states its negative control before its result.
